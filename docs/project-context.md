## 1. قرارات مُقفلة (لا تُعاد مناقشتها دون قرار جديد)

| # | القرار | التفاصيل |
|---:|---|---|
| 1 | الفصيل ثابت | يُختار عند إنشاء الشخصية فقط. Soft Launch وما بعده: **لا تغيير فصيل قتالي**. اختياري لاحقاً فقط: «زيّ ثقافي» تجميلي مدفوع — بلا وحدة خاصة جديدة ولا بونص فصيل ولا تبديل قتالي. |
| 2 | تسعير مسار الموسم | مستوى متوسط: هدف **≈ $4.99 USD**؛ توطين **≈ 18.99 ر.س (SAR)**؛ EGP بسعر متوسط لمتجر التطبيقات المحلي. **المسار المجاني ذو قيمة حقيقية دائماً.** |
| 3 | قلعة التحالف | **Must-have قبل بدء الموسم 1.** تُسلَّم في Soft Launch (Phase 2) كشرط لحروب العروش. Vertical Slice (Phase 1) = تحالف أساسي فقط بلا قلعة. |
| 4 | المحرك | **Unity** لعميل iOS/Android — مؤكَّد. |
| 5 | أسماء أبطال الإطلاق | تُبقى: أسد الرمال / قائد الفيلق الذهبي / فارس النوروز. مراجعة ثقافية قصيرة قبل تسويق Soft Launch — **ليست إعادة تسمية الآن.** |
| 6 | فصائل الإطلاق | ثلاثة فقط: راية الجزيرة/الخلافة، روما/بيزنطة، الفرس/الساسانيون. الباقي محتوى موسمي/Phase 3+. |
| 7 | نموذج القتال | تقرير محسوم على السيرفر عند وصول المسيرة — لا أكشن لحظي. سقف مساهمة البطل ≤ 25%. |
| 8 | إيقاع الموسم | 4–6 أسابيع (الموسم 1 = 5 أسابيع). عروش إقليمية قبل أي KVK (Phase 4). |
| 9 | اللغة | عربية RTL أولى. |

## 2. قيود التصميم (Constraints)

- لا وحدات/أبطال بكامل القوة للبيع المباشر؛ لا محتوى موسمي مدفوع يحسم حرب العروش.
- لا تبديل فصيل بعد الإنشاء في أي مسار مجاني أو مدفوع قتالي.
- الأسطورة تعزّز التكتيك ولا تستبدل الجيش/التحالف؛ مراجعة حساسية ثقافية قبل النشر.
- حماية مستودع تصاعدية؛ سقوف شراء موارد يومية.
- نوافذ عروش تراعي أوقات الذروة العربية (مرجع: AST).
- Phase 1 لا يتجاوز قصر 5، ولا فرسان/حصار/مواسم/عروش/متجر مدفوع/قلعة تحالف.

## 4. قواعد النقد والتحصيل (Monetization Rules)

### مسموح
- تجميل (مدينة، أبطال، رايات؛ لاحقاً زيّ ثقافي تجميلي).
- مسار موسم مدفوع بالسعر المقفل أعلاه + مسار مجاني مفيد.
- تسريع معتدل؛ حزم موارد بسقف؛ ماس يُشترى ويُكتسب مجاناً بمعدل معروف.

### ممنوع
- بيع قوة قتالية كاملة؛ دروع/حزم «احذف خصمك».
- وحدات حصرية مدفوعة تحسم العروش.
- صناديق عشوائية بلا شفافية احتمالات (إن وُجدت: نسب + ضمانات رحمة).
- مسار موسم أجوف مجاناً أو سعر خارج الشريحة المتوسطة دون قرار جديد.

### هدف سمعة
خلال 3 مواسم: إيراد التجميل + الموسم **أعلى** من إيراد تسريع القتال الصرف.

## 5. التحالف وقلعة التحالف (متطلب عبر المراحل)

| المرحلة | التحالف | قلعة التحالف |
|---|---|---|
| Phase 1 — Vertical Slice | إنشاء/انضمام، رتب مبسّطة، مساعدة بناء | **خارج النطاق** |
| Phase 2 — Soft Launch | كامل أساسي + بحث/خزينة حسب النطاق | **Must-have** — ترقية + حصار مرتبط بالعروش |
| الموسم 1 | شرط المساهمة في العروش | **جاهزة قبل الإطلاق**؛ جزء من حرب العروش |
