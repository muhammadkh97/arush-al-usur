## 4. تبسيطات مقصودة (ليست انحراف تصميم)

1. **عميل متصفح بدل Unity** — لا محرر Unity على بيئة السحابة؛ الجداول Unity-ready.
2. **`localStorage` بدل سيرفر تطوير** — استمرارية جهاز واحد؛ التحالف مشترك لنفس أصل المتصفح.
3. **`timeScale=60`** — ثانية ≈ دقيقة لعب؛ أرقام الجداول الأصلية كما في الوثائق.
4. **مساعدة التحالف** — زر يطلب مساعدة ويطبّق التخفيض فوراً (محاكاة عضو حليف).
5. **مضاد القتال** — مشاة/رماة (+خاصة مُصنَّفة)؛ تضاريس محايدة؛ NPC بلا سور.
6. **لا Push حقيقي** — إشعارات داخل الجلسة (toast + نافذة تقرير).

## 5. حكم القبول للشريحة الوثائقية

النموذج يثبت حلقة First Playable / M2–M3 على المتصفح مع جداول L1–5 متوافقة مع الوثائق.  
**القبول النهائي لـ Phase 1 على Unity + سيرفر تطوير (M4 كامل على جهاز)** يبقى معلقاً حتى مشروع Unity — خارج قيود هذه الجولة السحابية.

**الخلاصة:** Phase 1 Vertical Slice **مُسلَّم كشريحة متصفح + حزمة بيانات**؛ جاهز كنموذج أنظمة ومصدر جداول لفريق Unity.

## 6. تحديث الخرائط (مزدوج)

| العرض | ما يثبته |
|---|---|
| خريطة العالم الخارجية | سطح SVG استراتيجي (ليس قائمة أزرار): قلاع لاعب/NPC/وهمي تحالف، وحوش أسطورية مبسّطة، حقول موارد، حصون/أطلال/مواقع؛ تحديد عقدة → استطلاع / جمع / هجوم عبر أنظمة المسير والقتال القائمة؛ بيانات `data/world_map_slice.json` |
| خريطة داخل القلعة | مخطط مكاني شبه ايزومتري لمباني الشريحة؛ النقر يفتح لوحة ترقية/تدريب بدل قائمة مسطحة فقط |

التنقّل: تبويبا «داخل القلعة» و«خريطة العالم» + أزرار عبور بينهما. خارج النطاق لم يتغيّر (مواسم/عروش/متجر/فرسان-حصار/متعدد لاعبين حقيقي).
