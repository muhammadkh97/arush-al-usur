# Scenes (create in Unity Editor)

Folder placeholders for Soft Launch. Create empty scenes here in Unity and add them to Build Settings:

| Scene | Purpose |
|---|---|
| `Boot.unity` | Service bootstrap + RTL + table load |
| `MainMenu.unity` | Main menu |
| `CharacterCreate.unity` | Faction / start |
| `City.unity` | 3D city / castle (U1) |
| `WorldMap.unity` | Strategic map (U3) |
| `AllianceFortress.unity` | Soft Launch fortress (U5 / S1) |
| `DevSandbox.unity` | Local experiments |

Camera / lighting parity with the browser prototype: see `docs/unity-phase2-bootstrap.md` §3.
