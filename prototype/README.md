# عروش العصور — نموذج عمودي (Phase 1)

شريحة متصفح عربية RTL تُثبت حلقة: **إنشاء → داخل القلعة → تدريب → خريطة العالم → غارة/جمع → تقرير → تحالف/مساعدة → بطل**.  
المحرك المستهدف لاحقاً: Unity. هذا النموذج + حزمة `/data` يثبتان الأنظمة والجداول.

## الخريطتان

| العرض | التبويب | ماذا ترى |
|---|---|---|
| **داخل القلعة** | «داخل القلعة» | مخطط مكاني (شبه ايزومتري) لمباني الشريحة؛ انقر مبنىً للترقية/التدريب |
| **خريطة العالم** | «خريطة العالم» | SVG استراتيجي قابل للسحب/التكبير: قلاع، وحوش، حقول موارد، حصون/أطلال، معسكرات NPC |

تنقّل سريع: أزرار «خريطة العالم ←» و«→ داخل القلعة» داخل كل عرض.

## التشغيل محلياً

يجب خادم HTTP بسيط (لأن الجداول تُحمَّل من `../data/` عبر `fetch`):

```bash
cd /cursor/stores/self
python3 -m http.server 8080
```

ثم افتح: [http://localhost:8080/prototype/](http://localhost:8080/prototype/)

### جوّال / PWA
- واجهة phone-first مع `viewport-fit=cover` وهوامش safe-area
- `manifest.webmanifest` + أيقونات SVG — قابل للإضافة للشاشة الرئيسية
- خريطة العالم: سحب + قرص إصبعين للتكبير؛ أهداف لمس ≥44px
- جرّب عرض ~390×844 أو أدوات المطوّر → جهاز

بديل:

```bash
cd /cursor/stores/self
npx --yes serve -p 8080
```

لا تفتح `index.html` كملف `file://` — سيفشل تحميل JSON.

## ماذا يفعل النموذج

| النظام | السلوك |
|---|---|
| الشخصية | اسم + أحد ثلاثة فصائل؛ **مقفول** في `localStorage` بلا مسار تغيير |
| داخل القلعة | خريطة داخلية مكانية للمباني؛ طابور بناء واحد؛ إنتاج كل تكة |
| الجيش | مشاة خفيفة + رماة + وحدة خاصة للفصيل؛ بلا فرسان/حصار عامة |
| خريطة العالم | قلاع/وحوش/موارد/حصون + ≥20 معسكر؛ استطلاع؛ مسيرات متعددة بمسارات/ETA/استدعاء؛ جمع باحتلال |
| المستشفى | جرحى → طابور شفاء بمؤقّت + مساعدة تحالف |
| المهام | واجهة يومية مربوطة بـ `quests_daily_slice.json` مع تحصيل |
| القتال | صيغ `economy-combat-tables.md` + `data/combat_constants_slice.json`؛ سقف بطل 25٪ |
| البطل | بطل الفصيل؛ مستوى/مهارة؛ تجهيز×2 |
| التحالف | إنشاء/انضمام/مغادرة محلي؛ مساعدة بناء تخفض المؤقّت |
| المهام | 3–5 يومية تمنح موارد/تسريع |

## زمن التطوير

`timeScale = 60` افتراضياً: **ثانية حقيقية ≈ دقيقة لعب** حتى تكتمل حلقة ≤25 دقيقة. الجداول الأصلية بالدقائق لم تُغيَّر — التسريع طبقة محاكاة فقط.

## إعادة التعيين

زر **جديد** في الشريط العلوي يمسح شخصية المتصفح الحالية.

## بيانات Unity

المصدر المشترك للجداول: [`../data/`](../data/) — JSON جاهز للاستيراد/التوليد إلى ScriptableObjects.

## خارج النطاق (متعمد)

مواسم، عروش، قلعة تحالف، متجر مدفوع، فرسان/حصار عامة، قصر >5، سيرفر متعدد اللاعبين الحقيقي.
